Funciones y límites

Explora la función f(x) = (x² − 9)/(x − 3), definida para x ≠ 3. El límite existe aunque f(3) no esté definida.

x = 2.800
f(x) = 5.800
Límite esperado: 6

La función se simplifica a x + 3 solo cuando x ≠ 3. El punto (3,6) es un hueco, no un valor de la función original.

Comprender el procedimiento

Reto recuperado de nuestra Agenda Maestra: límite cuando x tiende a 3 de (x²−9)/(x−3).
