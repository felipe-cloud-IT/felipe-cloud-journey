# Fénix Academia — Laboratorios Trimestre II

**Estado:** prototipo de pruebas. No integrado a la academia productiva.

## Módulos
- Matemáticas II: funciones, límites, gráficas y procedimientos.
- Física I: cinemática con predicción y comprobación.
- Lógica y Estructuras Discretas: operaciones booleanas y tablas de verdad.
- Creatividad e Innovación: propuestas y evaluación de alternativas.
- Ética, Tecnología y Sociedad: decisiones responsables en casos simulados.

## Uso y privacidad
Abrir `index.html` en un navegador actualizado. Sin instalación ni dependencias externas.
El avance se guarda localmente en el navegador y se puede exportar como JSON. No ingresar información real identificable o privada: este repositorio es público.

Material de estudio **independiente del Equipo Fénix**. No implica afiliación, aprobación ni certificación de terceros.
No sobrescribir las aplicaciones existentes; comprobar funcionalidad en navegador antes de integrar.
